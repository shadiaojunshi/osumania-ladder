# 天梯身份层与悬浮交互

日期：2026-09-19。以下为本地实现和验证记录，尚未部署。

## 已实现

- 默认进入整场比赛，框内显示比赛全名。
- 整场比赛的一次悬浮会话固定卡片坐标，鼠标移动/滚动只更新所命中的轮次；进入卡片可操作详情和链接。离开后下一次悬浮重新定位。
- 每轮图池和整场比赛共用 RangeSurface：统一难度渐变坐标，熔岩头在同一按钮内渐隐，保留每轮重叠布局。
- 图标使用 public/tournament-icons/<比赛完整 id>.<扩展名>，构建生成索引，无图标不做网络探测。加载失败保留标题。
- 首次可见且加载成功后，保留原貌 5 秒，随后标题淡出、完整图标淡入并轻微缩放。减少动态效果模式也等待 5 秒，但不做过渡。
- 图标在框体与可视区交集的中心，随列宽及可见高度缩小，以 contain 完整呈现。透明图片保留透明，不透明图片保留底色，不对原图做边缘渐隐或裁切。难度范围、颜色坐标和点击选轮不变。

## 已确认但暂不实现：每轮重叠遮挡

用户认可保留重叠布局，通过可点击的轮次标题将目标框临时置顶，并在重叠区域提供轮次选择。后续单独实现：

1. 当前标题层仍不接收指针；后续将可选轮次标题改为键盘可操作按钮。
2. 每列保存一个 activeRoundId，仅改变显示层级，不改变难度坐标或宽度。
3. 重叠位置依据真实范围收集候选轮次，弹出选择列表；触屏使用点击，不依赖悬浮。
4. 切换模式/比赛/筛选后清理失效选中项；Esc 可取消临时置顶。
5. 验证标题与框体事件不会互相触发，轮次详情仍走统一入口。
