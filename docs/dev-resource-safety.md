# 开发验证资源安全记录

## 2026-08-28：开发服务器探测导致系统资源耗尽

### 现象

启动 `next dev` 后，同时发起多个 PowerShell/HTTP 探测。其中对 `/_not-found` 的请求触发了 Turbopack 编译并长时间等待，随后 Node 报：

`FATAL ERROR: Zone Allocation failed - process out of memory`

Windows 随后提示系统资源不足，导致其他软件卡顿或崩溃。

### 根因

这是验证操作的并发和资源控制失误，不是 MWC 标尺、整轮参考或图池清除逻辑抛出的业务异常。开发服务器在编译期间叠加多个探测命令，放大了 Turbopack 的内存占用。

### 以后执行规则

- 不使用 `Promise.all` 并发启动开发服务器、HTTP 请求或日志探测。
- 启动开发服务器后，只串行执行一个目标请求；请求必须设置较短超时。
- 业务逻辑优先用测试、TypeScript 检查和生产构建验证；需要浏览器验证时才启动服务器。
- 每次验证结束都确认开发服务器、探测命令和端口已经退出/释放。
- 出现 OOM 或系统变卡时立即停止验证，不继续叠加命令。

### 结果

本次未删除项目文件，功能测试和 TypeScript 检查均通过，开发进程已停止。
