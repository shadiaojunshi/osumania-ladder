# 比赛图标

把图片放在本目录，文件名必须是比赛 JSON 中的完整 `id`，区分大小写。
例如 `swm2-2026.png`（请先核对实际 id，不要使用比赛缩写代替）。

支持 PNG、WebP、JPG、JPEG、SVG、AVIF。每个 id 只能保留一个文件。
建议长边 512–1024 像素，尽量压缩至 300 KB 内。透明图片推荐 PNG / WebP；
不透明图片也支持，会完整等比显示，不会强行抠底或把上下内容渐隐。
SVG 仅放站长认可的本地素材，避免引用外部资源。

加入/更换图片后重启 `npm run dev -- --port 3022 --webpack`，或运行正常 build。
生成器在构建时检测文件；无图标的比赛不请求图片，不播放动画。
浏览器加载失败时也保留全名，不显示破图。

比赛第一次进入可视区且图片加载成功后，保留原貌 5 秒，再淡入徽章。
徽章位于比赛框可见部分的中央，跟随可见范围变化；使用 contain 完整显示。
原难度范围、渐变、熔岩边界和点击选轮不变。开启减少动态效果时不播放过渡。
